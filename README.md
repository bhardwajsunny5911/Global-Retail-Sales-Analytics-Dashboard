📊 Global Retail Sales Analytics Dashboard | Power BI

An interactive Power BI dashboard built to analyze global retail sales performance, customer behavior, product trends, and regional profitability. This project transforms raw retail transaction data into actionable business insights through interactive visualizations, advanced DAX calculations, and executive-level reporting.
